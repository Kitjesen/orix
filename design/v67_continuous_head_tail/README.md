# V67：头尾连续性修正

## 用户指出的问题

V66 尾部横条与背盖分裂；后脑过窄，头部与肩部曲面不一致。本轮调整实体和分件方式。

## 实际变化

1. 删除独立 body_tail_cap 组件，将其区域纳入 body_upper 的同一外、内放样实体。取消上表面尾盖横向分缝。后板仍独立可拆，尾部底部保留回边。
2. 头部最靠后的截面控制半宽，从上/下 48/42 mm 改为 66/60 mm；下一截面改为 69/63 mm。其余前部截面沿用，保留面部、耳轴、安装孔和低位姿态。
3. 重建 head_upper 与 head_lower，保留四个安装柱、螺钉孔和耳轴开孔。
4. 重建前肩，纵向过渡从机身较前中段开始，横向采用根据后脑轮廓拟合的平滑函数；取消第一遍渲染中不自然的局部凹痕。
5. 头部仍固定且可拆，保留约 1 mm 的轴向拆装缝。本轮没有恢复转动关节，也没有改变机架、电机与腿部位置。
6. 暖白/石墨/冷灰/青色材质保持与 V66 相同，避免颜色掩盖形状变化。

## 文件与过程

- comparison.html：V66/V67 同视角侧视、俯视、尾部切换及三视图。
- cad/SD-V67_continuous_head_tail.SLDASM、同名 STEP：原生装配。
- process/body_editable_master.SLDPRT：背部、尾部和肩部的外内放样母体。
- process/head_editable_master.SLDPRT：新头部外内放样母体。
- scripts/build.py、render.py、check_fit.py、check_native_contacts.py：过程代码。
- process/first_pass：首遍曲面出现凹痕的预览与脚本，保留修订过程。
- process/shoulder_fit.json：横向轮廓拟合残差。

## 验证

原生装配已保存并重新打开，30 个组件（取消单独尾盖）引用正常。3 个改动件均为单一闭合正体积网格。

改动件对机架及其余零件的检查中，头下壳与支架、四颗安装螺钉共 5 对出现网格接触候选；原生实体求交均无正体积重叠，也没有未解析结果。后续只修改前肩横向曲面函数，这些安装零件保持同一输入和构造；复查接触候选没有增加。

四条腿在现有临时限位内共 588 个离散姿态未发现改动件与腿部接触。没有连续扫掠或实物验证。

SolidWorks 本轮文档已关闭，用户原有应用实例保留。原阶段保留 V66 并在本地保存；本仓库现在收录这一 V67 快照。

## 明确的剩余差距

这不是生产定型。头身分缝保留；后脑与前肩是近似轮廓匹配，采样拟合残差最大约 2.55 mm，不是严格相切或曲率连续性认证。头后两侧接缝附近与尾部下缘仍可继续细化。取消尾盖独立拆分后，背盖需整体拆下，后板可单独拆。

上盖固定、壳体密封、完整电子器件与线束、全件最小壁厚、强度与散热仍未定型。原生装配含机架、壳体、安装件，预览腿部来自 URDF，不能称为完整生产装配。
