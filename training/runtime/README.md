# SmallDog V67 / MoE-CTS 仿真接入

本目录固定采用 V67 外观、原机架和 12 关节、电池。V67 头部和耳朵在本轮作为固定组件。

## 当前资产与训练（2026-10-14）

当前运动资产为 `v67_sim_r3`：大腿位置范围包含零位，calf 最大绝对角度扩到 2.10 rad；默认站姿与高度沿用 r2。几何采样、真实 Isaac 站立/扩展动作、平地/多地形接触和 80 环境热启动测试已通过。参数来源为 `joint_motion_config.json`；当前范围、证据和启动记录见 [TRAINING_R3_20261014.md](TRAINING_R3_20261014.md)。r2 历史记录见 [JOINT_WINDOW_R2_20261013.md](JOINT_WINDOW_R2_20261013.md)。

FlatGait 600 次迭代和后续 RoughGait 1800 次追加迭代均已完成，最终模型 `model_2398.pt`。速度课程已解锁到 1.0 m/s，平均地形等级 3.64。独立测试：1.0 m/s 平地实际均速 0.922、16 环境 10 秒 0 次终止；80 环境多地形实际均速 0.892、7 次终止，全部在台阶组。结果与剩余问题见 [R3_RESULTS_20261014.md](R3_RESULTS_20261014.md)。下文早期批次记录为历史。

## 数据和假设

- 壳体及安装件来自 `design/v67_continuous_head_tail/assembly.json` 对应实际闭合网格，按记录的 PETG / 铝 / 钢密度计算体积、质量、质心、惯量；没有使用旧 V3 外壳惯量。
- 电池继续采用 1.6 kg 占位；头部电子件预留 0.2 kg，计算板预留 0.15 kg。两项电子质量未实测。
- 总质量估算 13.902960 kg；基础机械零件惯量保留原记录。
- 计算板占位从 z=126 mm 下移至 110 mm，避免穿出 V67 上盖。这是仿真布置提案，安装结构尚未设计。
- 用户在 2026-10-12 确认 calf 按总等效 2∶1 接入。RS02 模组输出轴之后的速比乘一次，不重复乘内部 7.75。
- 仿真名义条件 48 V。hip/thigh 力矩限幅 7 N·m；calf 为 14 N·m。速度上限分别 42.9351 / 21.4675 rad/s。DCMotor 线性饱和包络采用 17 / 34 N·m 截距，是保守近似，不是官方完整 T-N 曲线或热模型。
- 输出轴旋转惯量 hip/thigh 0.0042 kg·m²，calf 按速比平方折算为 0.0168 kg·m²。
- 初始 PD：hip/thigh Kp=40、Kd=0.8；calf Kp=60、Kd=1.5，均为关节端仿真整定值。
- 位置限位采用本轮基于模型采样并经过 Isaac 验证的仿真窗口，详见当前资产报告；不是实测硬止挡。动作目标裁剪到各区间中间 90% 的软窗口。
- 上盖、头部和耳朵使用分离凸包，侧板和腹部采用简单碰撞体；保留原腿部碰撞和四个独立足端。碰撞代理不能替代 CAD 干涉检验。

以上配置支持仿真开发，不是实机控制参数确认。

## 文件

- `joint_motion_config.json`：当前运动窗口、默认站姿、root 高度、软限位和动作缩放的来源。
- `build_asset.py`：从 V67 源文件、运动参数和已保存的外观预览重新生成质量、碰撞和完整资产。
- `assets/smalldog_v67/urdf/smalldog_v67.urdf`：新的仿真 URDF。
- `assets/smalldog_v67/config/model_contract.json`：质量明细、初始角度和假设。
- `overlay/`：合入 Go2 RL RobotLab 源码的 SmallDog 专用配置和验证脚本。

环境 ID：`RobotLab-SmallDog-V67-Flat-v0`。
算法：上游 `OnPolicyRunnerCTS` / `ActorCriticMoECTS`，8 专家，teacher 环境比例 75%。
首轮任务：低速平地；前后速度 -0.15～0.35 m/s、横移 ±0.10 m/s、转速 ±0.3 rad/s。

## 服务器命令

工程：`/root/autodl-tmp/workspace/smalldog_cts_moe`。
此服务器 Isaac 的无显示 GPU 启动使用现有 EGL Vulkan ICD：

```bash
cd /root/autodl-tmp/workspace/smalldog_cts_moe
export VK_ICD_FILENAMES=/root/autodl-tmp/vulkan/nvidia_egl_icd.json
./python.sh scripts/smalldog/check_import.py --headless --device cuda:0
./python.sh scripts/rsl_rl/train.py --task RobotLab-SmallDog-V67-Flat-v0 --headless --device cuda:0 --num_envs 128 --max_iterations 200
```

先检查 `validation/v67_import/report.json`，通过质量、关节、足端和静止支撑检查后启动训练。CPU 网络测试、URDF 静态检查和真实 Isaac rollout 是不同的证据。

## 本轮结果与 R2

- 真实 Isaac 导入和 5 秒静止支撑检查通过，报告在 `validation/isaac_import_report.json`。
- R1：128 环境、200 次迭代已完成，614400 个环境步；保存 `model_199.pt`。
- R1 学生策略测试：16 环境、10 秒、0.2 m/s 前进指令，0 次终止，平均速度约 -0.000388 m/s，平均绝对误差 0.200388 m/s。说明只学到了支撑，尚未学会跟随前进指令。
- R2：线速度奖励核 std 从 0.5 改为 0.2，角速度 std 从 0.5 改为 0.35，增加权重 0.25 的足端离地时间奖励（阈值 0.12 s）。机器人、限位和 2∶1 传动不变。
- `continue_v67_r2.sh` 从指定 R1 checkpoint 继续，512 环境、1800 次额外迭代。RSL-RL 恢复时计数从 199 开始，因此迭代编号可能重叠一轮。
- 尚未证明稳定行走。训练结果必须再次使用学生策略测试实际速度和姿态。
- 启用相机时 RTX 插件仍出现原生崩溃；无相机模式的物理仿真和训练已运行。没有提供虚构的 Isaac 渲染图。
