# 当前模型参数

版本：`v67_sim_r3`。以下为当前仿真资产配置，角度单位为 rad，长度为 m。

左右关节符号不同来自 URDF 轴定义；不能只复制同一组符号到另一侧。`fr/fl/rr/rl` 分别表示右前、左前、右后、左后。

默认根高度为 **0.2674918209 m**，总质量估计 **13.902960 kg**。关节目标使用硬范围中间 90% 的软窗口，hip / thigh / calf 动作缩放为 0.15 / 0.20 / 0.20 rad。

## 执行器

| 关节 | 力矩限幅 | 速度限幅 | Kp | Kd | armature |
| --- | ---: | ---: | ---: | ---: | ---: |
| hip / thigh | 7 N·m | 42.93510 rad/s | 40 | 0.8 | 0.0042 kg·m² |
| calf | 14 N·m | 21.46755 rad/s | 60 | 1.5 | 0.0168 kg·m² |

calf 按总等效 2∶1 接入，不重复乘电机内部减速比。DCMotor 的饱和截距为 17 / 34 N·m，是当前仿真的近似包络，不是经实机验证的完整热模型。

## 外观与质量假设

- 头部和耳朵在本轮 URDF 内为固定外观，不能将其解释为已实现转头或耳部执行器。
- 电池 1.6 kg，头部电子件 0.2 kg，计算板 0.15 kg 均含占位或估计。
- 裸主板包络为 220×120×2 mm，仿真布置中心 Z=110 mm；完整器件、接口、安装、线束和散热尚未定型。
- 碰撞使用原腿部碰撞、机身简单几何以及上壳/头/耳凸包代理。
- 关节窗口经过模型采样和 Isaac 检查，不等于实测机械止挡。
- README 图片采用默认角度作静态 FK；视觉足底离地与真实接触需在物理仿真中分别核对。
